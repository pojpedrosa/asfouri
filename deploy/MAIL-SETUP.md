# asfouri mail — receive on the droplet, send via Mailgun (EU)

Same model as Magna Carta: **Postfix** on the droplet receives mail and reads
forwarding rules live from the app DB; **Mailgun (EU)** relays outbound. Each
address can forward externally, land in the back-office inbox, or both — managed
in the admin under **Correio**.

```
incoming ──MX──▶ Postfix (157.230.108.100)
                   │  virtual_alias_maps = sqlite: asfouri DB (mail_addresses)
                   ├─▶ forward_to ……………… relay out via Mailgun SMTP (EU)
                   └─▶ <local>@inbox.asfouri.local ─pipe─▶ php artisan mail:store ─▶ Inbox
```

## 1. DNS records for asfouri.media

> asfouri.media's DNS zone lives in a DigitalOcean account that the `gaiaeducation`
> `doctl` can't see. Add these in that account (or grant access and they can be
> scripted). DKIM is generated by Mailgun in step 2 — add it once you have it.

| Type  | Name            | Value                                   | Notes |
|-------|-----------------|-----------------------------------------|-------|
| MX    | `@`             | `mail.asfouri.media` (priority 10)      | receive on droplet |
| A     | `mail`          | `157.230.108.100`                       | the droplet |
| TXT   | `@`             | `v=spf1 include:mailgun.org ~all`       | SPF (Mailgun send) |
| TXT   | `mta._domainkey`| _(DKIM value from Mailgun, step 2)_     | DKIM |
| CNAME | `email`         | `eu.mailgun.org`                        | Mailgun tracking (EU) |
| TXT   | `_dmarc`        | `v=DMARC1; p=none; rua=mailto:postmaster@asfouri.media` | DMARC |

## 2. Mailgun (EU) sending domain

In the Mailgun dashboard (EU region) add domain **asfouri.media**, copy the DKIM
TXT record into DNS above, and create SMTP credentials. Then on the app:

```
MAIL_MAILER=mailgun
MAILGUN_DOMAIN=asfouri.media
MAILGUN_SECRET=<mailgun sending api key>
MAILGUN_ENDPOINT=api.eu.mailgun.net
```

## 3. Postfix on the droplet

```bash
sudo apt-get update && sudo apt-get install -y postfix postfix-sqlite
# main.cf
sudo postconf -e 'myhostname = mail.asfouri.media'
sudo postconf -e 'mydestination = localhost'
sudo postconf -e 'virtual_alias_domains = sqlite:/etc/postfix/sqlite-virtual-domains.cf'
sudo postconf -e 'virtual_alias_maps = sqlite:/etc/postfix/sqlite-virtual-aliases.cf'
sudo postconf -e 'transport_maps = hash:/etc/postfix/asfouri-transport'
# outbound relay via Mailgun (DO blocks port 25)
sudo postconf -e 'relayhost = [smtp.eu.mailgun.org]:587'
sudo postconf -e 'smtp_sasl_auth_enable = yes'
sudo postconf -e 'smtp_sasl_security_options = noanonymous'
sudo postconf -e 'smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd'
sudo postconf -e 'smtp_tls_security_level = encrypt'

# lookup maps (from this repo's deploy/postfix/)
sudo cp deploy/postfix/sqlite-virtual-*.cf /etc/postfix/
echo 'inbox.asfouri.local  asfouri-inbox:' | sudo tee /etc/postfix/asfouri-transport
echo '[smtp.eu.mailgun.org]:587  postmaster@asfouri.media:<MAILGUN_SMTP_PASSWORD>' | sudo tee /etc/postfix/sasl_passwd
sudo postmap /etc/postfix/asfouri-transport /etc/postfix/sasl_passwd
# inbound pipe transport
cat deploy/postfix/master-cf-snippet.txt | sudo tee -a /etc/postfix/master.cf
# the deploy user must be able to traverse to the sqlite DB
sudo chmod o+x /var/www/asfouri-prod /var/www/asfouri-prod/database
sudo systemctl restart postfix && sudo ufw allow 25/tcp
```

Reading rules live from SQLite means the admin (**Correio → Endereços**) updates take
effect immediately — no Postfix reload needed when adding/removing addresses.
